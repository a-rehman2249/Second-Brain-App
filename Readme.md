# Second Brain App

## Overview
This is second brain app where user can store different type of content like google docs, youtube video , twitter tweets etc.

User can login to their account and can easily access their stored content.

## Features
- User Authentication (Sign up and login).
- Store different type of content
- Review and manage stored content

## Future plans
- Add search functionality(Can use vector db or elastic search)
- Add tags functionality(new tag added act as global tag)
- Improve UI/UX

## Tech Stack
- Frontend: React js with type script
- Backend: Typescript
- Database: MongoDB
